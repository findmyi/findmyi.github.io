# 支付宝当面付接入指南

> 目标：用户扫码付款 → 支付宝回调 → **自动解锁，零人工**
>
> 前提：**必须有营业执照**（个体工商户或企业）。个人身份证签不了。

---

## 为什么必须有个体户

支付宝「当面付」是**商户产品**，签约主体只能是：

| 主体类型 | 能不能签 |
|---|---|
| 个体工商户 | ✅ |
| 企业 | ✅ |
| 个人（无执照） | ❌ 不行 |

**这不是支付宝故意为难人** —— 是央行对商户收单的监管要求。个人码收经营款本身就是灰色地带。

---

## 第一步：办个体户（1–3 天，免费）

### 办理渠道

| 渠道 | 地址 | 说明 |
|---|---|---|
| **各地政务网** | 搜索「XX 省 企业开办一网通办」 | 多数省份线上全流程，免费 |
| **支付宝/微信小程序** | 搜「个体户注册」 | 部分省份支持 |
| **线下市监局** | 当地市场监督管理局 | 当场办结 |

### 需要的材料

```
1. 身份证
2. 经营场所证明（自己家也行，填住宅地址）
3. 名称（如「XX 文化交流工作室」）
4. 经营范围：建议填
   · 文化艺术交流活动策划
   · 信息技术咨询服务
   · 数字内容制作服务（不含出版发行）
   · 设计、制作、代理、发布广告
```

**注意**：经营范围里**不要**出现「培训」「教育」「出版」，那几个需要前置审批。

### 拿到什么

```
营业执照（电子版即可）
统一社会信用代码
```

1. 打开 https://b.alipay.com
2. 用**营业执照**注册企业支付宝账号（不是个人账号）
3. 完成实名认证（法人身份证 + 对公账户或法人个人银行卡）

## 第三步：创建应用并签约当面付

1. 打开 https://open.alipay.com
2. **控制台** → **创建应用** → 选「网页/移动应用」
3. 应用名称填：`周易六十四卦`
4. 创建后进入应用 → **产品绑定** → 添加 **「当面付」**
5. 点 **签约** → 提交资料（营业执照、法人身份证、经营场景说明）
6. **等审核**（通常 1–3 个工作日）

## 第五步：我这边配置

你把三样东西给我，我执行：

```powershell
cd D:\zhouyi-site\worker

'你的APPID'      | wrangler secret put ALIPAY_APP_ID
'整段私钥'        | wrangler secret put ALIPAY_PRIVATE_KEY
'整段支付宝公钥'   | wrangler secret put ALIPAY_PUBLIC_KEY
```

然后改 `wrangler.toml`：

```toml
[vars]
PAY_PROVIDER = "alipay"
```

重新部署即可。

## 技术实现说明

已经写好在 `worker/pay.js` 的 `alipay` provider 里：

| 环节 | 实现 |
|---|---|
| 下单 | `alipay.trade.precreate`，返回二维码内容 |
| 签名 | RSA2（RSASSA-PKCS1-v1_5 + SHA-256），WebCrypto 原生 |
| 验签 | 用支付宝公钥校验回调，**篡改必失败** |
| 回调 | `POST /notify`，验签通过才标记已付 |
| 前端 | 用本地 `assets/qrcode.js` 把内容渲染成二维码 |

**已验证**（`build/test-alipay-sign.mjs`，17 项全过）：

- PEM 头尾剥离正确
- 参数按 key 升序拼接
- 签名能被验签通过
- **改了订单号 → 验签失败**
- **加了参数 → 验签失败**
- **别人签的名 → 验签失败**
- 回调参数解析正确

## 过渡期怎么办

**执照没下来之前，用现在的人工确认模式先跑。**

配置在 `assets/payment.js`：

```js
payQr: {
  wechat: 'assets/qr-wechat.png',
  alipay: 'assets/qr-alipay.png',
},
```

这个已经生效，后台地址：

```
https://zhouyi-api.huangminzhe321.workers.dev/admin
```

执照下来、当面付签好后，把 `PAY_PROVIDER` 改成 `alipay`，
收款码就不会再显示了，改成实时生成的商户订单二维码。
