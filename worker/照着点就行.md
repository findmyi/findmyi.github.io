# 照着点就行 · 部署清单

> 目标：让付费墙真正能用（付款 → 拿码 → 输码 → 看到正文）
> 预计 **40–60 分钟** · 成本 **0 元**
>
> **每一步都有「怎么验证」** —— 做完一步就验一次，不要攒到最后。

---

## 准备

**需要的账号**：Cloudflare（免费）
**需要的工具**：Node.js（你已有）、PowerShell

**先打开这个文件夹**（后面会用到）：

```
D:\zhouyi-site\worker\
```

---

# 第 1 步：注册 Cloudflare（5 分钟）

**1.1** 打开 https://dash.cloudflare.com/sign-up

**1.2** 填邮箱 + 密码 → 注册 → 去邮箱点验证链接

**✅ 验证**：能进到 Cloudflare 控制台（左侧有一排菜单）

---

# 第 2 步：建 KV 存储（3 分钟）

**2.1** 左侧菜单 → **Storage & Databases** → **KV**

**2.2** 点 **Create namespace**（或 Create instance）

**2.3** 名字填：

```
ZHOUYI
```

**2.4** 点创建

**✅ 验证**：KV 列表里出现 `ZHOUYI`，点进去能看到 ID（一串 32 位字符，**先复制下来备用**）

---

# 第 3 步：建 Worker（5 分钟）

**3.1** 左侧菜单 → **Workers & Pages**

**3.2** 点 **Create** → 选 **Worker** → 点 **Get started**

**3.3** 名字填：

```
zhouyi-api
```

**3.4** 点 **Deploy**（先部署一个默认的）

**3.5** 部署完点 **Edit code**（或 Continue to project → Edit code）

**3.6** 把编辑器里的**全部默认代码删掉**

**3.7** 打开 `D:\zhouyi-site\worker\index.js`，**全选复制**，粘进编辑器

**3.8** 点右上角 **Deploy**

**✅ 验证**：
- 页面顶部显示你的 Worker 地址，形如 `https://zhouyi-api.xxxxx.workers.dev`
- **复制这个地址**（后面要用）
- 浏览器打开 `地址/health`，应该看到 `{"ok":true,"ts":...}`

---

# 第 4 步：绑定 KV 和密钥（5 分钟）

**4.1** 在 Worker 页面 → **Settings** → **Bindings**（或 Variables）

**4.2** 加 KV 绑定：

| 字段 | 填什么 |
|---|---|
| 类型 | **KV Namespace** |
| Variable name | `KEYS` ← **一字不差** |
| KV namespace | 选 `ZHOUYI` |

点 **Save**

**4.3** 加管理员密钥：

| 字段 | 填什么 |
|---|---|
| 类型 | **Secret**（或 Environment Variable，选加密） |
| Variable name | `ADMIN_TOKEN` ← **一字不差** |
| Value | **你自己设一个随机串**，例如 `zhouyi-2026-x7k9m2` |

点 **Save**

> ⚠️ **把这个 token 记在安全的地方** —— 它是你发码的钥匙。

**✅ 验证**：Bindings 列表里有 `KEYS` 和 `ADMIN_TOKEN` 两项

---

# 第 5 步：导出并灌入付费正文（10 分钟）

**5.1** 打开 PowerShell，跑：

```powershell
cd D:\zhouyi-site
& 'C:\Users\谦哲\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe' -X utf8 build\export-content.py
```

**✅ 验证**：输出 `64 条，合计 611,714 字符`，并生成 `worker\content-kv.json`

---

**5.2** 装 wrangler：

```powershell
npm i -g wrangler
```

**5.3** 登录：

```powershell
wrangler login
```

会弹浏览器 → 点 **Allow**

**✅ 验证**：PowerShell 里显示 `Successfully logged in`

---

**5.4** 灌正文：

```powershell
cd D:\zhouyi-site
wrangler kv bulk put --namespace-id=你的KV_ID worker/content-kv.json --remote
```

> 把 `你的KV_ID` 换成第 2.4 步复制的那个 ID

**✅ 验证**：Cloudflare 控制台 → KV → `ZHOUYI` → 应该看到 **64 条** `content:` 开头的键

---

# 第 6 步：生成授权码（3 分钟）

**6.1** 在 PowerShell 里跑（把两个地址换成你的）：

```powershell
curl.exe -X POST https://zhouyi-api.你的子域.workers.dev `
  -H "content-type: application/json" `
  -d "{\"action\":\"issue\",\"token\":\"你的ADMIN_TOKEN\",\"count\":200,\"tier\":\"PREM\"}"
```

**✅ 验证**：返回 200 个码，形如：

```json
{"ok":true,"count":200,"keys":["ZY-PREM-7K2M-9QX4-M", ...]}
```

**6.2 把这批码存下来** —— 这就是你卖的东西。

建议存成一个 txt 文件，放安全的地方。

**✅ 再验一次**（看统计）：

```powershell
curl.exe -X POST https://zhouyi-api.你的子域.workers.dev `
  -H "content-type: application/json" `
  -d "{\"action\":\"stats\",\"token\":\"你的ADMIN_TOKEN\"}"
```

应该显示 `{"ok":true,"total":200,"used":0,"unused":200,"revoked":0}`

  -H "content-type: application/json" `
  -d "{\"action\":\"stats\",\"token\":\"你的ADMIN_TOKEN\"}"

  -d "{\"action\":\"issue\",\"token\":\"你的ADMIN_TOKEN\",\"count\":500,\"tier\":\"PREM\"}"

```powershell

  -d "{\"action\":\"revoke\",\"token\":\"你的ADMIN_TOKEN\",\"key\":\"ZY-PREM-7K2M-9QX4-M\"}"
```

**改了正文要更新**：

cd D:\zhouyi-site
# 改 content\v3\*.md，然后：
& 'C:\Users\谦哲\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe' -X utf8 build\md2premium.py

## 卡住了怎么办

| 症状 | 原因 | 解决 |
|---|---|---|
| `地址/health` 打不开 | Worker 没部署成功 | 回第 3 步，确认点过 Deploy |
| `wrangler` 命令找不到 | 没装 | `npm i -g wrangler` |
| bulk put 报错说找不到 namespace | 用了 `--binding` 但没配 | 改用 `--namespace-id=` |
| 解锁后提示「未配置服务端地址」 | `workerUrl` 没填 | 回第 7 步 |
| 解锁后提示「取回正文失败」 | KV 里没有正文 | 回第 5 步，确认 64 条都在 |
| 提示「已绑定到另一台设备」 | **正常** —— 一码一人生效了 | 无 |

## ⚠️ 三条红线（别碰）

1. **不用「免签支付」**（码支付/虎皮椒/迅虎）
   2025 年判例：搭免签系统沉淀他人资金 → **非法经营罪，四年**

2. **不用「前端生成码」**
   F12 就能看穿，等于免费公开站

3. **不把正文放进 `articles/` 或 `data/`**
   正文只能放 KV
