# 100 人验证计划

> 来源：根源《AI时代到底怎么赚钱？先去做离钱最近的事》里的方案
> 原话：**「前面五十个人说愿意是掌声，后面五个人把钱转过来，才是答案。」**

---

## 为什么做这个

你现在有 37 万字内容、一个网站、384 条铁律。

**但你不知道有没有人愿意付钱。**

这个计划的作用：**用最低成本回答这一个问题。**

成本：
- 时间：20 天，每天 3–5 人，每次 15–30 分钟
- 钱：**0 元**
- 风险：**几乎为零**（你不是在卖，是在问）

---

## 怎么做

### 第一步：列名单（今晚就能做）

**从通讯录开始**，列出**最近 3 年内有过实际交流**的人。

分类记录：

| 类别 | 说明 | 预计人数 |
|---|---|---|
| **A. 正在卡住的人** | 你明确知道他在纠结去留/转型/低谷 | ? |
| **B. 可能卡住的人** | 最近半年状态不对 | ? |
| **C. 同行/相关** | 做内容、做咨询、做知识付费 | ? |
| **D. 其他** | 泛泛之交 | ? |

**优先聊 A 和 B。**

**目标 100 人**，如果通讯录不够，扩展到：
- 微信群（你所在的群，逐个私聊）
- 过往同事
- 校友
- 小红书/知乎上跟你互动过的人

### 第二步：怎么开口（这是关键）

**不要这样说**：
> ❌「我做了个周易网站，你能帮我看看吗？」（这是求人）

**要这样说**：
> ✅「我最近在研究一件事 —— 人在做去留决定的时候，到底是怎么卡住的。想找你聊 15 分钟，听听你的经历。我会给你一份我自己整理的东西作为回馈。」

**几个要点**：
1. **说清楚只要 15 分钟**（降低心理门槛）
2. **说清楚是「听你说」，不是「我讲给你听」**（他不是在被推销）
3. **承诺给回馈**（那份《要不要辞职》的判断工具）

### 第三步：聊什么（照着问）

**不要问「你需要什么」** —— 他答不出来。

**要问具体的事**：

```
1. 你最近有没有在纠结什么事？（工作上、生活上）
2. 那件事你纠结多久了？
3. 你都跟谁聊过？他们说了什么？
4. 你有没有想过该怎么办？为什么没做？
5. 如果有个东西能帮你理清，你希望它是什么样？
6. （在他讲完之后）我这个东西你看看，像不像你说的？
```

**第 6 步最重要** —— 把《要不要辞职》发给他，**看他的反应**。

### 第四步：记录（每聊完一个立刻填）

| # | 姓名 | 关系 | 卡在哪 | 纠结多久 | 跟谁聊过 | 看完文章的反应 | 愿付钱吗 | 为什么 |
|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | |
| 2 | | | | | | | | |
| … | | | | | | | | |

**「愿付钱吗」这一栏，不要问「你愿不愿意支持我」。**

**要直接报价**：
> 「如果我花一小时帮你把这件事理清，收 199，你会买吗？」

**然后记录三个结果之一**：
- 🟢 **当场转钱** → 真需求
- 🟡 **说会买但没转** → 待观察（大概率不是真需求）
- 🔴 **说不买** → 真反馈（问他为什么）

### 第五步：20 天后统计

```
聊了 ___ 人
🟢 当场付钱 ___ 人
🟡 说会买 ___ 人
🔴 不买 ___ 人

最常见的问题是：______
最常被问的反对意见是：______
```

---

## 判断标准

| 结果 | 结论 | 下一步 |
|---|---|---|
| 🟢 **≥ 3 人付钱** | **需求真实存在** | 正式做产品，涨价 |
| 🟡 有人说会买但没人付 | 需求存疑 | 换一个切入角度再测 |
| 🔴 **几乎没人感兴趣** | **这个定位有问题** | 停下来重新想，**别硬做** |

**根源的原话**：
> 「前面五十个人说愿意是掌声，后面五个人把钱转过来，才是答案。」

---

## 三个坑

### 坑 1：白嫖是默认状态

> 「会有人没有任何边界感地占用你的时间，还不会道谢。」

**对策**（来自辰风的实际做法）：
- 朋友圈先谈钱建立认知
- 简单问题发免费资料，**细节问题按小时报价**
- 让对方写反馈做筛选（愿意写的人才是认真的人）

### 坑 2：别接你接不住的问题

> 「你不能试图去解决每一个用户的问题，你只能解决你能够解决的问题。」——辰风
>
> 「客户连结构化数据都没有时别碰 —— 输入是乱的，输出一定是乱的。」——小挣青年

### 坑 3：不要一开始就定年费

> 「别一开始就定 199 元一年 —— 你把自己锁死了。」
>
> **早期月付更好，因为每个月都有钱进账。**

## 一句话

**这不是营销，是调研。**

**你不是在卖东西，你是在用一个 199 元的报价，去问出「这件事到底有没有人要」。**

**20 天，0 成本，答案就出来了。**
