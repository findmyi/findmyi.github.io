# 付费内容写作规则

> **硬约束。** 写本站付费内容前必读。违反任何一条，重写。
> 本规则基于对渤海小吏原文的实测归纳（见 `bohaixiaoli-writing-method.md`），
> 不是凭印象写的。

---

## 零、一句话总纲

**用户花钱买的不是「知识」，是「出路」。**

他读完一篇，要能认出自己在哪一档，知道下一步做什么。
做不到这一点，写得再准确也是失败。

---

## 一、骨架（已定稿，62 卦照此执行）

```
# X卦 · <读者处境式的标题>

<开头段：一个具体的、读者认得出的处境。不介绍卦是什么。>
<第二段：点出这一卦讲的是什么位置、什么问题。>

---

## 初九 · <爻辞> —— <判词>

> **初九：<爻辞原文>。**
> 象曰：<象传原文>

**你现在在这个位置：<一句话定位>**

<动作：具体到能照做，给判断标准>
<史事：一句话讲完某人的某个选择，只做佐证>

**什么情况可以破例：**<例外>

---

## 九二 · <爻辞> —— <判词>
...（六爻依次）

---

## 最后：<全卦总结>

<收尾，给一句能带走的话>
```

**每爻四段，缺一不可**：处境定位 → 动作 → 史事 → 例外。
这四段分别回答读者的四个问题：我在哪？我该干嘛？谁这么干过？什么时候不该这么干？

> **关于「三层分层」的说明**：研究渤海小吏时归纳出的「三档分层」
> （三流的 X / 二流的 X / 一流的 X）是他写单篇随笔的骨架，
> **不适用于逐爻解读**。卦有六爻，天然就是六个位置 —— 那就是分层。
> 所以本骨架采用「六爻逐爻」，不用「三档」。

## 二、铁律

### 1. 学术只能当佐料
正史、考证的唯一作用：**证明我讲的事是真的**。
- ✅ 「这事《史记》里有。」
- ❌ 「王弼与程颐在此存在分歧……」

**学术一旦成为骨架，产品就死了。**

### 2. 禁用清单

| 禁止 | 原因 |
|---|---|
| 【待核】 | 不确定就删，别让用户替你把关 |
| 说明 / 声明 / 注释 | 用户买内容，不是看免责条款 |
| 参考文献 / 注明出处 | 要提就在句子里顺口带一句书名 |
| 各家观点 / 分歧 / 一说 / 另说 | 考证癖 |
| ⚠️ 开头的提示块 | 同上 |
| 「本节」「上文」「下文」 | 破坏叙事 |
| **「我们」** | 渤海小吏全文 0 次 |
| 大段引用原文或注疏 | 每次只引一句 |
| 引用某学者观点作依据 | 框架永远是「在我看来」 |
| 超过 3 句的长段落 | 单句成段是常态 |
| 描述性小标题 | 用判词、画面、绰号、问句 |

### 3. 句式纪律（实测修正）

```
❌ 禁止：「之所以……是因为……」
   —— 解释因果、证明对错。渤海小吏全文 0 次。

✅ 允许：「不是 A，而是 B」
   —— 但只能用在段落结尾做排比收束，不能用来论证。
   例：你不再是被影响、被调动，而是影响他人、创造价值。
```

**我之前一刀切禁掉这个句式，反而把文字写僵了。**

### 4. 必须做

- ✅ 卦名放**标题末尾方括号**里当标签（如【屯、蒙、需、讼】）
- ✅ 标题主体是**读者的处境**，不是卦名
- ✅ **一组 2–3 卦打包**，不按单卦卖
- ✅ 用一个历史人物或一场战役**跑一遍这一卦**
- ✅ 引史料**只引一句**，用情绪动词包裹
- ✅ 金句单独成段放结尾
- ✅ **雅俗词混用**（吃瓜 + 东施效颦）

---

## 三、分层，不是分选项

**这是最容易做错的一点。**

❌ 错误写法（我原来写的）：
> 如果你 A，就做 X；如果是 B，就做 Y。

✅ 正确写法（渤海小吏的）：
> 三流的见识是关于消费的……
> 二流的见识是关于生产的……
> 一流的见识是关于创造的……

**读者先自认在哪一档，再往上一档走。**

「几个出路」不是给并列选项，是靠**三档分层**实现的。

## 四、语气

### 人称
- **全篇用「你」**
- 「我」只出现一次，用于「在我看来」立框架，之后隐退
- **「我们」出现 0 次**

### 雅俗同体（他的指纹）
两类词混用：
1. **网络/职场口语**：吃瓜、赛道、大佬、跟班、入围赛
2. **成语/文言**：东施效颦、躬身入局、运筹帷幄

用文言词给网感内容加重量，用网络词给历史卸下沉重。

### 段落
- **1–3 句一段，大量单句成段。**
- 这是节奏的来源。

## 五、标题公式

```
【栏目名】+ 反差/悬念陈述 + ？ + 【本卦标签】
```

栏目名是系列品牌：【硬核】【深度】【官智经】【荣枯鉴】【天规地道】

**栏目名构造法**：
- **官智经** → 八个动词拆完当官一辈子：求迁、免谪、建功、化难、释疑、远谤、藏拙、去患
- **荣枯鉴** → 四组对立：善恶、贵贱、名实、福祸

**公式：一个「经/鉴/道」+ 一组穷尽性动词或对立词。**

**章节标题风格**（实测）：
- 判词：`水灌晋阳，韩魏反戈`
- 编号+画面：`第二战 破釜沉舟：力拔山兮气盖世`
- 绰号：`"苏指导"的艺术人生`
- **卦象入题**：`南龙有悔，北龙在天`（从「亢龙有悔」改写）

## 六、验收清单

- [ ] 标题是读者处境，卦名在末尾方括号里
- [ ] 开头 3 段不超 60 字，含问句 + 「在我看来」+ 分层宣布
- [ ] 三层分层，不是分选项
- [ ] 每层用一个具体场景开头，不是卦辞开头
- [ ] 每层只引一句古文
- [ ] 有「所以」起的转折枢纽
- [ ] 出路只给一个动作，重复三次
- [ ] 金句单独成段收尾
- [ ] 全篇无「我们」
- [ ] 无禁止清单任何一项
- [ ] 无「之所以……是因为……」
- [ ] 段落不超过 3 句
- [ ] 雅俗词混用
- [ ] 念出来像跟人说话，不像做报告

## 七、违例留存（真实犯过的错）

**违例 1｜学术骨架**
> 「坤卦在传统注疏中是被当作「臣道」来读的。可是六五是第五爻，而第五爻就是君位。于是程颐点出了一个结构性矛盾……」

问题：整段是文献分析，读者读完不知道自己该干嘛。

**违例 2｜免责声明**
> 「⚠️ 诚实声明：以下对三家观点的概括……凡未能逐字核对原文者，一律标【待核】……」

问题：把不确定性转嫁给用户。不确定就删。

**违例 3｜分选项而非分层**
> 「如果你现在是初爻，就攒；如果你在二爻，就找人。」

问题：这是并列选项，读者不知道该选哪个。应该分层——让他自认在哪一档。

## 八、逐卦执行标准（62 卦批量生产用）

### 1. 标题格式
```
## 初九 · 潜龙勿用 —— 别出声
        ↑爻辞原文      ↑判词
```
- 爻辞**过长时可截取核心词组**，但必须是原文里的字，不许自己改写
- 判词是白话概括，**要好记**（4–8 字为佳）
- 二者缺一不可：爻辞保证「和原文挂上」，判词保证「读者记得住」

### 2. 每爻的四段
```
> **初九：潜龙勿用。**
> 象曰：潜龙勿用，阳在下也。
                                    ← 原文块（爻辞 + 象传）
**你现在在这个位置：……**            ← 处境定位（一句，加粗）
                                    ← 动作（具体到能照做，含判断标准）
                                    ← 史事（一句话，只做佐证）
**什么情况可以破例：**……            ← 例外（必须有）
```

### 3. 史事是硬要求
- **每爻都要有**，不许空着
- 找不到就从 `_hex-index.json` 索引到的 19 部注疏里翻，或用《史记》《汉书》《资治通鉴》《左传》
- 允许「同一个人在不同爻出现」（如周公可证乾九三，也可证坤六五），但**讲的必须是这个人不同的选择**
- **上下文要接得上**：史事必须和这一爻的处境对得上，不能硬贴

### 4. 字数
- 每卦 2500–3500 汉字
- 每爻 300–450 字

### 5. 禁止（重申，最容易犯的）
- 「我们」—— 0 次
- 「之所以……是因为……」—— 0 次
- 待核 / 说明 / 声明 / 注释 / 各家观点 / 分歧
- 大段引用注疏（每次只引爻辞和象传，别的古文最多一句）

### 6. 可以用的（明确允许）
- 「不是 A，而是 B」—— 限段尾排比
- 口语：吃瓜、赛道、大佬、烂摊子、没劲了
- 文言词：躬身入局、东施效颦、如履薄冰
- **雅俗混用是他的指纹，也是我们的**
