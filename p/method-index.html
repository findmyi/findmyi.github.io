按处境速查

这是最实用的部分。找到最贴近你处境的类别，再看对应的卦：

进退抉择

  • 该不该前进 → 晋（进）、升（上升）、渐（循序渐进）
  • 该不该停下 → 艮（止）、遁（退避）
  • 进退两难 → 蹇（受阻）、屯（初生之难）
  • 想动但时机未到 → 需（等待）、小畜（积蓄）

顺境与逆境

  • 正处于顺境 → 泰、大有、丰（看它们怎么讲「守」）
  • 处于逆境 → 否、困、明夷（看它们怎么讲「处」）
  • 由盛转衰的警示 → 乾上九（亢龙有悔）、丰（日中则昃）
  • 否极泰来 → 否上九（倾否）、复（一阳来复）

做事与开创

  • 刚开始一件事 → 屯（艰难初创）、蒙（学习启蒙）
  • 需要积累 → 小畜、大畜
  • 需要果断行动 → 夬（决断）、大壮（强盛）
  • 需要变革 → 革（变革）、鼎（革新、建立新秩序）

人际与协作

  • 如何团结人 → 同人（与人和同）、比（亲附）、萃（聚集）
  • 如何处理冲突 → 讼（争讼）、睽（背离）
  • 上下级关系 → 临（居上临下）、观（观察与被观察）
  • 家庭关系 → 家人（家庭之道）、咸（感应）、恒（恒久）

修养与自处

  • 如何保持谦虚 → 谦（六爻皆吉）
  • 如何面对富足 → 大有、丰
  • 如何面对困境 → 困（困而不失其正）、坎（险中守信）
  • 如何修养自己 → 乾（自强不息）、坤（厚德载物）、颐（养正）

使用提示

不要只找一个卦。 同一个处境往往有多个卦对应不同侧面。比如「要不要辞职」——可能涉及遁（该退）、革（该变）、需（该等）、蹇（受阻）。

建议读两到三卦，对照着看，判断会更准。

也可以用右上角的搜索（⌘K / Ctrl+K）直接搜关键词，比如「进退」「等待」「诚信」。
